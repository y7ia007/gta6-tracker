# GTA VI Tracker – agreed requirements

- Private iPhone web app, added to Home Screen, works fully offline (except remote images until cached).
- UI entirely in English. Item names exactly as in game.
- Images embedded inline from their original source URLs (no "open image" buttons); "download all images" for offline.
- Checkbox per item, progress per category and overall, search, filter "not done".
- Per-category maps / location lists (banks, garages, barbers, bars, side missions, etc.).
- Look: GTA VI brand colours (no logo), glow + glass effects, premium feel; home page with story feel.
- Missions section:
  - Chapters in story order; missions inside each chapter in order.
  - Each mission: who gives it, where to go, step-by-step what to do, tips (in my own words).
  - Spoiler lock: only completed missions + the current one are visible. Next mission locked until current is checked. Next chapter hidden until all missions in current chapter done. Chapter summaries also locked.
- Tips / nudges: what to do next, money-saving tips, things not to miss (missable items) – written by me.
- Hosting: GitHub repo gta6-tracker -> GitHub Pages (public) or Vercel (private).
